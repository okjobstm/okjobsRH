# Dokumentacija javnog Okjobs API-ja

Okjobs nudi javne resurse za otkrivanje namenjene agentima i integratorima. Ovi endpointi ne zahtevaju autentifikaciju.

## Endpointi za otkrivanje

- API katalog: https://lobbystack.com/.well-known/api-catalog
- OpenAPI opis: https://lobbystack.com/openapi.json
- Status: https://lobbystack.com/api/status
- Kontekst za LLM: https://lobbystack.com/llms.txt
- Mapa šema: https://lobbystack.com/schemamap.xml
- Graf šeme stranica: https://lobbystack.com/schema/page.json
- Graf šeme bloga: https://lobbystack.com/schema/post.json
- Indeks agent skills resursa: https://lobbystack.com/.well-known/agent-skills/index.json
- Kartica MCP servera: https://lobbystack.com/.well-known/mcp/server-card.json

Mašinski endpointi u v1 ostaju kanonski na engleskom. Ova stranica prevodi dokumentaciju namenjenu ljudima.
