# Okjobs Discovery

Use this skill when an agent needs a concise, machine-readable orientation to Okjobs's public website, documentation, and open-source project resources.

## Resources

- Website: https://lobbystack.com/
- Product docs: https://docs.lobbystack.com/introduction
- API catalog: https://lobbystack.com/.well-known/api-catalog
- OpenAPI description: https://lobbystack.com/openapi.json
- LLM context: https://lobbystack.com/llms.txt
- Features markdown: https://lobbystack.com/features.md
- Pricing markdown: https://lobbystack.com/pricing.md
- Affiliate program markdown: https://lobbystack.com/affiliate-program.md
- Calculator markdown: https://lobbystack.com/missed-call-revenue-calculator/index.md
- GitHub repository: https://github.com/lobbystack/lobbystack

## Guidance

1. Start with https://lobbystack.com/llms.txt for a compact product overview.
2. Use https://lobbystack.com/.well-known/api-catalog to discover public machine-readable resources.
3. Use https://lobbystack.com/features.md, https://lobbystack.com/pricing.md, and https://lobbystack.com/affiliate-program.md for clean markdown summaries of the public site.
4. Use https://docs.lobbystack.com/introduction for product setup and self-hosting documentation.
5. Use https://lobbystack.com/pricing/ for canonical pricing details and https://lobbystack.com/features/ for canonical capability descriptions.
