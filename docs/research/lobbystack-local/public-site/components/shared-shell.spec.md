# Shared shell specification

## Overview

- Target: compiled Navbar, Footer and cookie UI in every embedded Astro document.
- Interaction model: sticky/scroll-driven header plus click-driven disclosures.

## DOM and styles

- Sticky `header.site-header`, centered `max-w-7xl` inner row and responsive desktop/mobile nav variants.
- Footer uses a bordered white surface, responsive two/four-column link grid and a final utility row.
- Exact computed values are supplied by the unmodified generated Astro CSS rather than re-estimated in Next.js.

## States and behaviors

- Header edge appears over the first 48px of scroll where scroll timelines are supported.
- Desktop and mobile `details` elements animate on open.
- Hover and focus states retain source colors, timing and focus rings.

## Assets and content

- LobbyStack SVG logo, GitHub SVG icon, locale copy and all original navigation/footer labels.

## Responsive behavior

- Desktop grouped navbar from the source `md` breakpoint.
- Mobile menu sheet below that breakpoint.
- Footer stacks and wraps exactly as generated by the source CSS.
